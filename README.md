# cybersecurity-task-11
Phishing Attack Simulation &amp; Detection
## Overview
This project demonstrates a controlled phishing attack simulation using **GoPhish** and **MailHog** to understand phishing techniques, user behavior, and prevention strategies.  
All activities were performed in a safe lab environment for educational purposes only.

## Objective
- Understand phishing and social engineering attacks  
- Simulate a real-world phishing scenario  
- Identify phishing red flags  
- Learn detection and prevention methods  

## Tools Used
- GoPhish – Phishing simulation framework  
- MailHog – Local SMTP email testing server  
- Kali Linux – Testing environment  

## Methodology
1. Studied phishing concepts  
2. Configured GoPhish server  
3. Set up MailHog as SMTP relay  
4. Created phishing email template  
5. Designed credential capture landing page  
6. Added test users (alice@company.com, bob@company.com)  
7. Launched phishing campaign  
8. Analyzed campaign results  

## Results
- Emails successfully delivered  
- Links clicked by users  
- Credentials captured  
- Campaign statistics monitored via GoPhish dashboard  

## Phishing Red Flags
- Urgent language  
- Fake sender identity  
- Suspicious links  
- Fear-based messaging  

## Prevention Methods
- Security awareness training  
- Email filtering  
- Multi-Factor Authentication (MFA)  
- SPF, DKIM, DMARC implementation  

## Disclaimer
This project is strictly for educational and authorized testing purposes.  
Unauthorized phishing attacks are illegal and unethical.

## Final Outcome
Improved understanding of phishing attacks, detection techniques, and cybersecurity awareness.
